# AbeloHost Blog

## Этап 1. Docker окружение

Этот этап разворачивает базовое окружение с PHP 8.1 (FPM), Nginx и MySQL 8.

1. Скопируйте `.env.example` в `.env` и при необходимости обновите переменные.
2. Добавьте запись в `/etc/hosts`, чтобы домен указывал на локальную машину:

   ```
   127.0.0.1 abelohost.test
   ```

3. Поднимите контейнеры:

   ```
   docker compose up -d
   ```
4. Проверьте отрабатывание nginx перейдя по следующей ссылке:

   ```
   http://abelohost.test
   ```
5. Зайдите в окружение php для запуска скриптов:

   ```
   docker compose exec php bash
   ```
